One archival idea: capture sources and preservation metadata form a SIP; a
validated self-contained representation plus SHA-256 fixity forms an AIP; an
accessible copy or rendered knowledge view forms a DIP. The preservation law
is not byte identity between every format. It is preservation of declared
semantic observations, provenance, resolvable identity, and verified fixity
across each versioned transformation.

This note builds on [[PKM_ARCHIVAL_ARCHITECTURE]] and is sourced from
[[20260804-infranodus-design-superset-journal]]. Both documents link back,
making the conceptual relationship explicitly traversable in each direction.

`observe(DIP(AIP(SIP(x)))) = required_observations(x)` holds only for the
registered observation set. Anything outside that set remains a preservation
residual, not an implicit guarantee.
