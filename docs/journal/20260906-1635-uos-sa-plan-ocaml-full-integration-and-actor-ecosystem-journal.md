## 8. Root Cause Analysis & Fix Taxonomy

During the integration and compilation process, two critical engineering challenges were identified and definitively resolved:

1. **Gleam Multiline Parenthesis Application Bug**:
   - **Root Cause**: In Gleam, writing `(list.length(catalog) >= 20)` on a new line immediately following a zero-argument function call `let catalog = sa_plan_bridge.actor_ecosystem_catalog()` caused the parser to interpret the parenthesized expression as an argument to `actor_ecosystem_catalog`, yielding `Type mismatch: This value is being called as a function but its type is List(...)`.
   - **Fix Taxonomy**: Refactored to intermediate boolean variables (`let has_min_catalog = list.length(catalog) >= 20; has_min_catalog |> should.be_true()`), eliminating syntactic ambiguity.
2. **Dune Library Export & State Path Isolation**:
   - **Root Cause**: Running `sa_plan_main.ml` in arbitrary working directories without parent directory creation caused SQLite connection errors on `state/sa_plan.sqlite3`.
   - **Fix Taxonomy**: Injected automated parent directory creation (`let dir = Filename.dirname db_path in if not (Sys.file_exists dir) then Unix.mkdir dir 0o755`) into `sa_plan_main.ml`.

## 9. Patterns & Anti-Patterns Discovered

### Discovered Patterns
- **Two-Lattice Single-Writer Fenced Leases**: In durable task engines, pairing an incrementing fencing token with a leased timestamp prevents split-brain split execution across network partitions.
- **Deterministic History Replay**: In Temporal workflows, testing execution by re-running activities against past history with a panic assertion verifies that activities are never re-executed upon replay.

### Discovered Anti-Patterns
- **Multiline Function Argument Ingestion in Gleam**: Starting lines with opening parentheses `(` without explicit assignment can turn statements into unintentional function application expressions.
