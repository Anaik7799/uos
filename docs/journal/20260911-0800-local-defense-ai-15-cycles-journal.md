## 6. Patterns & Anti-Patterns Discovered

- **Pattern: Pure Value Functional Derivative Pipelines**:
  Passing health samples by value to `health_derivative.update` and folding over immutable lists eliminates race conditions and garbage collection pauses.
- **Pattern: Comptime SIMD Vector Width Scaling**:
  Using `comptime float_simd_width = simd_width_of[DType.float32]()` in Mojo allows automatic scaling across AVX2, AVX-512, and ARM Neon architectures without changing code.
- **Anti-Pattern: Implicit Struct Copying in Mojo 1.0**:
  Attempting to copy structs without declaring `@fieldwise_init struct S(ImplicitlyCopyable, Movable)` fails at compile time. Using `@fieldwise_init` resolves this cleanly.
- **Anti-Pattern: Release Number Checking**:
  Release number strings (e.g. "29") can be spoofed; verifying store paths and deterministic derivations prevents toolchain drift.
