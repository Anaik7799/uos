The recurring defect is confusing a declaration or partial observation with end-to-end evidence. A catalog stage, successful command delivery, HTTP200, job enqueue, workflow activity, model answer or passing component count does not prove implementation or system admission.

The status falsifier changed only declared dependency edges: the visible Sa-plan task row still matched, but its original creation receipt no longer matched the exact command. One shared Gleam predicate now checks visible identity and the exact creation receipt in sync, dependency registration and status. Missing, changed or failed receipts cannot report successful registration.
