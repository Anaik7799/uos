## 4. Root Cause Analysis

### Challenge: Terminal Pager Hang on Unattended Command Runs
When running `jj status` or `jj log` in subshells without explicit flags, Jujutsu invokes `less` or the system pager, pausing for interactive input (`Press RETURN to continue`) and delaying automated execution.
- **Root Cause**: `jj` defaults to interactive paging when stdout appears to be a tty or when no pagination flag is specified.
- **Resolution**: Explicitly pass `--no-pager` on all `jj` invocations in automated agent scripts.

### Challenge: Unescaped Double Quote in Gleam String Literal
Inserting ASCII art into a multiline Gleam string literal (`"..."`) caused a syntax error because `HARD_DENIED_SYSTEM_OS_SERIAL = "25503L801736"` contained unescaped double quotes.
- **Root Cause**: Gleam string literals do not allow unescaped double quotes inside `"..."`.
- **Resolution**: Changed to single quotes `'25503L801736'` inside the ASCII box, satisfying both Gleam grammar and zero-warning compilation.
