1. **Epistemic Drift vs. Evidence Retention**: When transitioning across environments (VM-1 to NAS-1), previous implementations sometimes overwrite or conceal historical failures to present a superficial passing state. This violates epistemic honesty. UOS preserves the prior `Unavailable_observed` run as immutable historical evidence, contrasting it with the subsequent pure BEAM resolution.
2. **Ambient Path Fragility in Storage Kernels**: Standard POSIX operations relying on absolute or relative path strings (`open("/data/file")`) are susceptible to TOCTOU symlink races and directory jail escapes. The descriptor-relative paradigm (`openat(dirfd, path, O_NOFOLLOW)`) physically binds operations to an unforgeable directory capability.
