## 4. Root Cause Analysis

A stale installed Solo5 version and cached package-page results gave different answers about the latest toolchain. A fresh official release lookup resolved this: 0.13.0 is current. OCaml-Solo5 1.3.4 supports OCaml >=5.5 and <5.6; Mirage remains 4.11.2. The separate metrics worker is building that exact compatible closure in an isolated switch. It is not yet credited as completed here.

The prior probe also confuses a normal process exit with guest success. Upstream `test_hello` exits normally even for the wrong argument; on VirtIO both normal exit and intentional stack abort can return host status 83. Console semantics and process status must therefore be checked together.
