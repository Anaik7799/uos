## Supervision and evidence

`Masked | Unavailable | Engaged` is the outcome algebra. Only `Engaged` increments successful invocation counts. A computed rejection can be an engaged model result; it does not mean the rejected operation was performed. A subprocess timeout also does not prove an external effect rolled back.

One timer token prevents duplicate timer chains. One bounded external worker keeps state queries and heartbeats responsive. Actor failure discards volatile state and restarts within the OTP restart budget; a reset must be visible rather than represented as uninterrupted history. Process-group cleanup handles cooperating descendants; the release service cgroup provides the outer containment boundary. Arbitrary executable dispatch is not a public capability.

Local ticks rotate across all participants. Bayesian/ETS input comes from observed cadence. Fixed finite-model inputs are labeled diagnostics. MAX and remote model calls require an invocation and retain their outcome; no background request consumes a paid model.
