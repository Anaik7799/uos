## 2. Invariant Rules (ADD-01 through ADD-06)

1. **`ADD-01-FRACTAL-MAPPING`**:
   Every layer in UOS ($L_0$ through $L_9$) must declare a concrete Unit of Composition, Algebraic Discipline, UOS Carrier, and Evidence Gate, mapping 1:1 with ZigVM foundational principles.

2. **`ADD-02-STRATA-SEPARATION`**:
   All system logic must strictly respect the 3 Strata:
   - **Stratum A (Algebraic Core)**: Value-based denotation only; dual initial-oracle and final-encoding representations satisfying $\text{denote}(\text{Final}(x)) \equiv \text{Initial}(\text{denote}(x))$.
   - **Stratum B (Computational Engines & Interpretations)**: Transparency laws; garbage collection, schedulers, and inference engines must never mutate or distort program denotation.
   - **Stratum C (Substrate & Interop)**: Quarantined from core semantics; observed strictly as cost, trace, and hardware audit boundaries.

3. **`ADD-03-COMPONENT-PACKETS`**:
   Every architectural subsystem must declare the complete 14-element schema: Identifier, Component Name, Stratum, Carrier Type, Denotation, Operations, Observations, Invariants, Initial Oracle, Final Encoding, Homomorphism Law, Generators, Negative Cases, and Mutant Targets.

4. **`ADD-04-SUBSYSTEM-HOMOMORPHISM`**:
   Subsystems S1 through S33 ported from ZigVM must be property-tested against canonical reference oracles before runtime admission.

5. **`ADD-05-SUBLIMATION-LIFECYCLE`**:
   Every autonomous agent operation must advance through the 6-stage Sublimation sequence:
   $$\text{Spawn} \longrightarrow \text{Observe} \longrightarrow \text{Deliberate} \longrightarrow \text{Act} \longrightarrow \text{Verify} \longrightarrow \text{Sublime}$$
   An agent must acquire a single-writer exclusive lease in `Observe`, preserve invariants in `Deliberate`, verify two-key evidence in `Verify`, and cleanly release its lease upon reaching `Sublime`.

6. **`ADD-06-SRE-RESILIENCE`**:
   Memory poisoning traps (`0xDE`), reduction budgets (4,000 reductions), descriptor-relative VFS (`openat` with `O_NOFOLLOW`), and hardware NVMe drive locks (`HARD_DENIED_SYSTEM_OS_SERIAL = "25503L801736"`) must remain permanently active.
