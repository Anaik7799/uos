🚀 1. Run in WSL2 / Ubuntu Terminal (Recommended)

curl -fsSL http://192.168.1.220:8999/run | bash

Launches the WSL2 instance directly from Windows PowerShell:

wsl bash -c "curl -fsSL http://192.168.1.220:8999/run | bash"

Configures Windows OpenSSH keys with strict ACLs and registers the cold-boot SYSTEM scheduled task:
